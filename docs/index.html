Use it in Python

  
The same renderer and settings in Jupyter and Streamlit.

  

    

      
Jupyter · ipyspeck

      
pip install ipyspeck

      
from ipyspeck import Speck
w = Speck.from_alphafold("Q8W3K0")
w.apply_preset("cover")
w.save_image("figure.png", width=3000)
w.save_video("movie.mp4", "tour")

    

    

      
Streamlit · stspeck

      
pip install stspeck

      
import stspeck
stspeck.speck(**stspeck.fetch_pdb("4HHB"),
              surface=True, surfaceOpacity=0.3,
              preset="glossy", height=500)
